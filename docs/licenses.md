# 사용하는 외부 라이브러리와 라이선스

PRD 7.4 원칙 7. 판매 단계에서 라이선스 문제로 막히지 않도록 새 의존성을 추가할 때마다 여기에 적습니다.

| 이름 | 용도 | 라이선스 | 판매 시 주의 |
| --- | --- | --- | --- |
| Python 3.11 | 언어 | PSF | 없음 |
| PySide6 (Qt 6) | 화면 | LGPL-3.0 | 동적 링크 유지, 라이선스 고지, 사용자가 Qt 라이브러리를 교체할 수 있어야 함 |
| FFmpeg | 음량 분석·처리 | LGPL-2.1+ (빌드 옵션에 따라 GPL) | 판매용 설치 파일에는 `--enable-gpl` 없이 빌드한 LGPL 버전을 넣고 고지. 현재 개발용은 conda-forge 빌드 사용 (`ffmpeg -L`로 확인) |
| numpy | 테스트 | BSD-3-Clause | 앱에는 포함하지 않음 |
| pytest | 테스트 | MIT | 앱에는 포함하지 않음 |
